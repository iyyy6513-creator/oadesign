OA DESIGN 홈페이지 — 수정 안내
================================

[ 구성 ]
  index.html   사이트 전체 (디자인·글·기능이 이 파일 하나에 다 들어있음)
  img/         사진 66장

[ 수정하는 법 ]
  깃허브 저장소에서 index.html 클릭 → 오른쪽 위 연필(✏️) 아이콘 클릭
  → 고치고 → 아래 Commit changes → 1분 뒤 사이트에 자동 반영
  ※ 반영이 안 보이면 Ctrl+F5 (맥은 Cmd+Shift+R) 로 새로고침

  파일 안에서 원하는 곳을 찾을 때는 Ctrl+F 로 검색하세요.


────────────────────────────────
1. 지금 비어 있는 것들  ← 우선 채우세요
────────────────────────────────

■ 전화번호
  검색 : <dt>Tel</dt>
  현재 : <dd>-</dd>
  수정 : <dd>062-000-0000</dd>

■ 이메일  ★ 중요 — 문의가 이 주소로 갑니다
  파일 안에 2군데 있습니다. 둘 다 바꿔야 합니다.
  검색 : hello@oadesign.kr
   (1) <a href="mailto:hello@oadesign.kr">hello@oadesign.kr</a>  ← 화면 표시용
   (2) location.href = 'mailto:hello@oadesign.kr?subject=      ← 실제 전송용

■ 주소
  검색 : <dt>Address</dt>
  현재 : <dd>광주광역시</dd>

■ 상담 시간
  검색 : <dt>Hours</dt>

■ SNS 링크
  검색 : <dt>Channel</dt>
  현재 : Instagram · Blog · KakaoTalk   (글자만 있고 링크는 없음)
  링크로 만들려면 :
    <dd><a href="https://instagram.com/아이디" target="_blank">Instagram</a> ·
        <a href="https://blog.naver.com/아이디" target="_blank">Blog</a></dd>


────────────────────────────────
2. 프로젝트 정보
────────────────────────────────
  검색 : const projects
  아래와 같은 덩어리가 9개 있습니다.

    { title: "수완지구 자이", loc: "광주 광산구", area: "-", type: "아파트",
      desc: "화이트와 오크 톤을 중심으로 ...",
      thumb: "img/56-9c0849b787.webp", thumb_w: 1250, thumb_h: 834,
      images: ["img/56-...", "img/57-...", ...] }

    title   프로젝트 이름
    loc     위치
    area    면적   ← 대부분 "-" 입니다. "34평 / 112㎡" 처럼 채우세요
    type    유형   (아파트 / 상가 / 사무실)
    desc    설명
    thumb   격자에 보이는 메인컷
    images  클릭했을 때 아래로 넘어가는 사진들

  ★ 1번 "신규 현장" 은 이름과 위치를 아직 안 정했습니다.
  ★ 6번 "수완지구 대방3차 (2)" 는 3번과 이름이 겹칩니다.
  ★ 순서 바꾸기 : { ... } 덩어리를 통째로 잘라서 위아래로 옮기세요.
  ★ 프로젝트 지우기 : { ... } 덩어리 하나를 통째로 지우고, 앞 덩어리 끝의
                      쉼표(,)가 남지 않게 정리하세요.


────────────────────────────────
3. 사진 다루기
────────────────────────────────
■ 사진 교체 (같은 자리에 다른 사진)
  img 폴더에 같은 이름으로 덮어쓰기

■ 사진 추가 (8·9번 상세 사진 등)
  1) 깃허브에서 img 폴더 클릭 → Add file → Upload files 로 사진 올리기
  2) index.html 의 해당 프로젝트 images 목록에 파일명 추가
     images: ["img/65-8313d18cf8.webp", "img/새사진1.webp", "img/새사진2.webp"]

■ 메인컷 교체
  thumb 을 바꾸고, thumb_w / thumb_h 도 그 사진의 실제 픽셀로 같이 고치세요.
  ※ 메인컷은 가로 사진(3:2)이 가장 잘 맞습니다. 세로 사진은 위아래가 잘립니다.

■ 첫 화면 큰 사진
  검색 : class="landing"
  img 의 src 를 바꾸세요. 이 사진은 잘리지 않고 통째로 보입니다.
