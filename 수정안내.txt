OA DESIGN — 원페이지 포트폴리오 사이트
=====================================

[ 폴더 구성 ]
  index.html   사이트 본체 (HTML + CSS + JS 한 파일)
  img/         현장 사진 66장 (WebP)

[ 올리는 법 ]
  index.html 과 img 폴더를 통째로 웹호스팅 루트에 올리면 끝입니다.
  index.html 만 옮기면 사진이 안 나옵니다. img 폴더를 꼭 같이 옮기세요.

[ 프로젝트 순서 (현재 9개) ]
  1  신규 현장             ← 프로젝트명 / 위치 입력 필요
  2  상무지구 갤러리303
  3  수완지구 대방3차
  4  수완지구 대방6차
  5  수완지구 현진에버빌1차
  6  수완지구 대방3차 (2)   ← 메인컷 아직 추정
  7  수완지구 자이
  8  원흥 A아파트 37평      ← 메인컷만 있음, 상세 사진 없음
  9  광장 B아파트 75평      ← 메인컷만 있음, 상세 사진 없음

[ 이미지 처리 방식 ]
  · 첫 화면 큰 사진 : 자르지 않고 통째로 보여줍니다.
                      가로가 남으면 좌우에 흰 여백이 생기고,
                      세로로 긴 화면(모바일)에서는 가로에 꽉 맞춰 짧아집니다.
                      어느 경우에도 한 화면을 넘지 않습니다.
  · 프로젝트 격자   : 한 줄에 3장, 타일 비율 3:2.
  · 상세(모달) 사진 : 원본 비율 그대로, 절대 잘리지 않습니다.

[ 수정할 곳 — index.html 을 메모장/VSCode 로 열고 Ctrl+F 로 찾기 ]

  1. 프로젝트 정보
     "const projects" 로 검색하면 아래 형태가 9개 나옵니다.

       { title: "원흥 A아파트", loc: "-", area: "37평", type: "아파트",
         desc: "사진 준비 중입니다.",
         thumb: "img/p8-cover.webp", thumb_w: 1600, thumb_h: 1200,
         images: ["img/p8-cover.webp"] }

       title / loc / area / type / desc  → 그대로 고치면 됩니다
       thumb + thumb_w + thumb_h         → 격자 메인컷 (세 개를 같이 고치세요)
       images                            → 클릭 시 아래로 넘어가는 사진들

     ★ 8·9번에 상세 사진 추가하기
       사진 파일을 img 폴더에 넣고 images 목록에 줄줄이 적으면 됩니다.
         images: ["img/p8-cover.webp", "img/p8-01.webp", "img/p8-02.webp"]
     ★ 순서 바꾸기: { ... } 블록 통째로 잘라서 위아래로 옮기면 됩니다.
     ★ 프로젝트 추가/삭제: { ... } 블록을 복사하거나 지우면 됩니다.
       3의 배수(9, 12개...)로 맞추면 격자가 딱 떨어집니다.

  2. 첫 화면 큰 사진
     class="landing" 으로 검색. img 의 src 를 원하는 파일로 바꾸세요.
     좌우 여백 색은 CSS 의 .landing{background:var(--bg)} 에서 바꿉니다.

  3. 회사 소개 (About)
     id="about" 으로 검색. 문구 3개와 숫자 3개(Since / Projects / A-S)를 바꾸세요.

  4. 연락처 (Contact)
     id="contact" 로 검색. 전화·이메일·주소를 바꾸세요.
     "hello@oadesign.kr" 이 파일 안에 2곳 있습니다 (표시용 + 문의 폼 전송용).

[ 참고 ]

  - 인트로(OA DESIGN) 시간: 스크립트의 setTimeout( ... , 1100) 숫자(밀리초).
