OA DESIGN — 깃허브에 올리기 (도메인 구입 불필요, 전액 무료)
============================================================

완성되면 이런 주소가 생깁니다
   https://내아이디.github.io/oadesign/

준비물 : 깃허브 계정(무료), 이메일. 결제 없음.
소요시간 : 15분


────────────────────────────────
1단계. 깃허브 가입
────────────────────────────────
github.com 접속 → Sign up → 이메일/비밀번호/아이디 입력
※ 여기서 정한 아이디가 주소에 그대로 들어갑니다.
  예) 아이디를 oadesign 으로 하면 → oadesign.github.io/...
  회사 이름으로 짓는 걸 권합니다.


────────────────────────────────
2단계. 저장소(repository) 만들기
────────────────────────────────
1) 오른쪽 위 [+] → New repository
2) Repository name : oadesign
   ※ 이 이름도 주소에 들어갑니다 → github.io/oadesign/
3) Public 선택
   ★ Private 은 무료 플랜에서 사이트가 안 열립니다.
     (아래 "공개 여부" 항목 참고)
4) Create repository


────────────────────────────────
3단계. 파일 올리기
────────────────────────────────
1) 저장소 첫 화면의 "uploading an existing file" 링크 클릭
2) 이 폴더 안의 것들을 통째로 끌어다 놓기
     · index.html
     · img 폴더
     · .nojekyll
   ★ 폴더 자체를 넣지 말고 "안에 있는 것들"을 넣으세요.
     index.html 이 맨 위층에 있어야 합니다.
3) 사진이 66장이라 1~2분 걸립니다. 다 올라갈 때까지 대기
4) 맨 아래 Commit changes 클릭


────────────────────────────────
4단계. 사이트 켜기
────────────────────────────────
1) 저장소 위쪽 Settings → 왼쪽 메뉴에서 Pages
2) Source : Deploy from a branch
3) Branch : main  /  (root) → Save
4) 1~2분 뒤 새로고침하면 위쪽에 주소가 뜹니다

끝입니다. 그 주소를 인스타 프로필이나 명함에 넣으면 됩니다.


────────────────────────────────
공개 여부에 대해
────────────────────────────────
무료 깃허브 페이지는 주소를 아는 사람 누구나 볼 수 있습니다.
친구·지인에게 링크를 보내면 바로 열립니다.

네이버·구글 검색에도 시간이 지나면 걸립니다.
카톡이나 문자로 링크를 보내면 대표 사진과 함께
미리보기가 뜨도록 설정해 두었습니다.

────────────────────────────────
나중에 도메인 붙이고 싶어지면
────────────────────────────────
oadesign.co.kr 같은 주소를 쓰고 싶으면
가비아·후이즈에서 도메인을 사고(연 1~2만원)
Settings → Pages → Custom domain 에 입력하면 됩니다.
지금 당장은 안 하셔도 됩니다.


────────────────────────────────
수정하는 법
────────────────────────────────
글자 수정 : 저장소에서 index.html 클릭 → 연필(✏️) → 고치고 Commit
            → 1분 뒤 사이트에 자동 반영
사진 추가 : img 폴더 → Add file → Upload files

어디를 고쳐야 하는지는 "수정안내.txt" 참고.


────────────────────────────────
안 될 때
────────────────────────────────
· 404 뜸        → index.html 이 맨 위층에 있는지 확인
· 사진만 안 나옴 → img 폴더를 안 올렸거나 경로가 img/img/ 로 중첩됨
· 수정이 반영 안 됨 → Ctrl+F5 (맥은 Cmd+Shift+R) 로 새로고침
